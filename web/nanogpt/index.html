Why a baseline?

        
To judge a new architecture you need a reference trained on the same data with the same budget. This GPT has
          ~12.6M parameters like the BDH demo and uses the same optimizer, learning rate and batch shape.

      

      

        
What runs here?

        
Upstream nanoGPT model.py, trained on a laptop and re-implemented in plain JavaScript with a KV
          cache, verified against the PyTorch forward pass.

      

      

        
Memory, compared

        
The KV cache grows by ~22 kB per byte (5.5 MB for a full window). BDH keeps a fixed 67 MB state: larger at
          this context length, but it never grows and has no window limit.
