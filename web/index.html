Same data (Tiny Shakespeare as bytes, 90/10 split), same optimizer (AdamW, lr 1e-3, weight decay 0.1), batch 16 × 256 bytes, dropout 0.1. Validation loss in bits per byte, best checkpoint; lower is better. Trained on a laptop.

  • Same data, BDH learns much more per byte: after 6.1M bytes BDH reaches 2.20 bits/byte, the Transformer 2.80.
  • Same time, it is a tie: a Transformer step is ~7× cheaper here, so in ~20 minutes nanoGPT sees 41M bytes and reaches 2.18 — within noise of BDH's 2.20.
  • Both start to overfit this 1 MB corpus: nanoGPT's best checkpoint is at step 7,500 of 10,000.
  • Caveats: one seed per run (differences below ~0.03 are noise), a laptop GPU through PyTorch MPS (BDH's large sparse layers may run relatively faster elsewhere), and one shared recipe with no per-model tuning (e.g. no learning-rate warmup, which Transformers usually like).
